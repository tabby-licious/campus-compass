# Campus Compass

A text-based Python program that helps Angelo State University students
find campus resources quickly: study help, food, health, careers,
tech support, recreation, and emergency contacts.

## Features
- Emergency contacts and help (shown first on the menu)
- Browse all campus resources
- Find resources by category
- Search resources by keyword
- Save and remove favorite resources

## How to run
1. Install Python 3.
2. Download or clone this repository.
3. Keep `main.py` and `resources.py` in the same folder.
4. In a terminal, run: `python main.py`

## Python concepts used
- Variables, input/output, and f-strings
- `while` loop, `if/elif/else`, and `for` loops
- User-defined functions
- Lists of dictionaries, plus a list inside each dictionary

## Important note
The resource information is starter data entered by hand. Hours and
contact details can change, so please confirm with each office. In an
emergency, call 911.
